# Заплатки на дерево tdesktop

Форком целого дерева не заводимся: tdesktop обновляется часто, и заплатку
проще переложить, чем разбирать конфликты во всём дереве. Коммит, на который
они ложатся, записан в `../tdesktop.pin`.

Как сделать новую:

    git -C tdesktop checkout <файл>          # начать с чистого
    ...правки...
    git -C tdesktop diff -- <файл> > desktop/patches/NNNN-имя.patch
    git -C tdesktop checkout <файл>          # вернуть дерево как было
    git -C tdesktop apply --check desktop/patches/NNNN-имя.patch

Последняя строчка обязательна: заплатка, которая не накладывается,
обнаруживается иначе только упавшим прогоном, а прогон стоит полтора часа.

## 0001-name

Клиент называется Margy, а не Telegram Desktop. Одна строка в
`core/version.h`.

Заплатка нарочно крошечная: её задача — не переименовать, а проверить, что
механизм работает от начала до конца. Пустое дерево уже собралось; если
теперь сборка сломается, сломала её заплатка, и больше нечему.

Про что стоит помнить дальше: на windows по `AppName` строится путь к папке
с данными. Значит на самом деле это не только надпись — у настоящей сборки
профиль будет лежать отдельно от официального телеграма. Для форка это
скорее нужно, чем нет, но знать об этом лучше заранее, чем удивляться.

## 0002-gradient

Первая настоящая часть Margy на десктопе: градиент профиля из общей группы.

Читается ровно то же, что пишет андроидная Margy, — сообщение вида
`#margy_gradient AABBCC-DDEEFF` в группе `margy_underground`. Чей градиент,
видно по автору сообщения; подделать нельзя, подпись ставит телеграм.
Договариваться клиентам между собой не о чем: источник один.

Куда врезано. У десктопа уже есть понятие «фон шапки профиля» —
`Ui::CreateTopBgGradient(size, peer, offset)` в
`ui/top_background_gradient.cpp`. Там одно место, где решается, каким цветом
быть шапке: подарочный градиент, потом телеграмовский цвет пира. Наш встаёт
первым, потому что человек выбрал его сам.

Чего тут нарочно нет:

  * группу не разыскиваем по сети. Не знаем про неё — значит человек в ней
    не состоит, и градиентов ему взять неоткуда; ходить в сеть при каждом
    открытии профиля ради украшения не стоит того;
  * никого не ждём. Пока не прочитано, профиль рисуется как обычно;
  * память живёт ровно столько, сколько сессия: выход из аккаунта уносит её
    с собой, иначе на следующем входе чужой профиль покрасился бы остатками
    прошлого.

Чего не знаю и врать не буду: у десктопа шапка — радиальный градиент
«центр — край», а у андроида наш градиент идёт снизу вверх. Какой из двух
цветов ставить в центр, я выбрал наугад (верхний в центр). Как посмотрим
глазами — поправим одной строкой.
